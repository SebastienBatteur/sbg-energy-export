# Sécurité / Security

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

- De préférence : onglet **Security → Report a vulnerability** de ce dépôt (signalement privé
  GitHub) ;
- ou par e-mail : **contact@sbg-energy.com**, objet « Sécurité SBG Energy Export ».

Indiquez la version de l'intégration, la version de Home Assistant, les étapes pour reproduire
et l'effet observé. Accusé de réception sous 7 jours ; correctif et avis publiés dès que possible,
en vous créditant si vous le souhaitez.

Sont dans le périmètre : le code de ce dépôt (intégration `custom_components/sbg_energy_export`
et script `outils/sbg_ha_export.py`). Le service analyse.sbg-energy.com et auth.sbg-energy.com se
signalent à la même adresse.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

- Preferably: this repository's **Security → Report a vulnerability** tab (GitHub private
  reporting);
- or by e-mail: **contact@sbg-energy.com**, subject "SBG Energy Export security".

Include the integration version, the Home Assistant version, steps to reproduce and the observed
impact. Acknowledgement within 7 days; fix and advisory published as soon as possible, crediting
you if you wish.

## Versions prises en charge / Supported versions

Seule la dernière version publiée reçoit des correctifs. / Only the latest release receives fixes.
